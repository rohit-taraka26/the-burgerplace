# 🍔 BurgerPlace — Responsive Burger Restaurant Website

BurgerPlace is a burger restaurant website built using HTML and CSS. It features a responsive layout, an attractive food card design, and interactive styling to provide a user-friendly browsing experience.

## ✨ Features

- Responsive website layout
- Navigation bar with section links
- Burger cards with a carousel-style layout
- CSS hover effects
- Mobile-friendly navigation menu
- Contact section with a map

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚀 How to View

1. Download or clone this repository.
2. Open the `index.html` file in your web browser.
